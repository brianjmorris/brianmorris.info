# brianmorris.info

[Visit brianmorris.info](https://brianmorris.info)

## Built with

- **Frontend:** HTML, JavaScript, and [Sass](https://sass-lang.com/).
- **Rendering:** [EJS](https://ejs.co/) templates with [Express](https://expressjs.com/) on [Node.js](https://nodejs.org/).
- **Hosting:** [Firebase Hosting and Cloud Functions](https://firebase.google.com/).
- **Background:** HTML Canvas with animated stars and pointer interactions.
